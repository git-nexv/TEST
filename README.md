# Noam Nex V Music

موزیک پلیر آفلاین (PWA) با ظاهر کاملاً شبیه Apple Music و نوار پایین **Liquid Glass**.

## قابلیت‌ها
- چهار تب Home / Radio / Library / Search دقیقاً مثل اپل موزیک (تم دارک)
- نوار پایین شیشه‌ای: با نگه‌داشتن و کشیدن به چپ/راست، حباب شیشه‌ای کش می‌آید، آیکون‌ها زوم می‌شوند و با فنر روی تب می‌نشیند
- مینی‌پلیر شیشه‌ای + صفحه Now Playing تمام‌صفحه (سوایپ به پایین برای بستن)
- ایمپورت آهنگ از Files گوشی (یا انتخاب یک پوشه کامل در دسکتاپ/اندروید)
- خواندن تگ‌های ID3 (عنوان، خواننده، آلبوم، کاور)
- پلی‌لیست: هر پلی‌لیست یک **پوشه واقعی** است و از هر آهنگ یک **کپی** داخل آن ساخته می‌شود
- Artists / Albums / Songs / Favorites / صف پخش / Shuffle / Repeat
- Media Session (کنترل از صفحه قفل)
- کاملاً آفلاین: فایل‌ها در OPFS و متادیتا در IndexedDB، پوسته برنامه در Service Worker

## ساختار پوشه‌ها (داخل فضای فایل برنامه)
```
NoamNexVMusic/
  Songs/                 ← همه آهنگ‌های ایمپورت‌شده
  Playlists/<نام>/       ← کپی آهنگ‌های همان پلی‌لیست
```

## اجرا
```bash
npm run serve      # http://localhost:8788
npm run deploy     # Cloudflare Workers (wrangler)
```
برای نصب PWA: در Safari آیفون → Share → Add to Home Screen؛ در اندروید/کروم → Install app.
بعد از اولین بازکردن، برنامه بدون اینترنت هم بالا می‌آید.
